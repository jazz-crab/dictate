# dictate — локальный голосовой ввод для Windows

Говорите — текст построчно появляется в окне по мере диктовки (живой
черновик), его можно поправить, и только потом скопировать в буфер или
сформулировать заново локальной LLM. Ничего не отправляется само.
Полностью локально, без внешних API.

## Как это работает

1. **Запись.** `Ctrl+Alt+D` — внизу плашка «ЗАПИСЬ n с»; микрофон уже
   открыт (писк звучит после открытия потока, чтобы начало фразы не
   уходило в тишину), окна пока нет — оно не мешает работать.
   `Ctrl+Alt+D` ещё раз или `Esc` — стоп/отмена.
   Пока идёт распознавание, плашка показывает «РАСПОЗНАЮ», и только
   потом появляется окно с готовым текстом.
   Ограничение длины — `max_seconds` (по умолчанию час).
   Живой черновик (текст в окне прямо во время речи) есть в коде, но
   выключен: `live.enabled: false` — на CPU хвост распознаётся дольше,
   чем человек говорит, и текст «догоняет» речь рывками.
2. **Распознавание.** `faster-whisper turbo` (CTranslate2, int8, CPU 4
   потока), `beam_size: 5` с таймстемпами. VAD выключен: silero даже с
   низким порогом вырезал тихое начало фразы, поэтому whisper получает
   запись целиком. После стопа идёт финальный проход по всему буферу —
   он же верифицирует живой черновик.
3. **Окно.** Обычное окно с заголовком и иконкой в панели задач (можно
   свернуть, переместить, изменить размер); растёт под текст, дальше —
   скроллбар. В шапке галочка **поверх всех** — окно висит над другими
   программами (снята — ведёт себя как обычное окно, ничего не
   перекрывает). Кнопки:
    - **Копировать в буфер** (`Ctrl+Enter`) — текст в буфер обмена,
      запись попадает в историю. Окно остаётся открытым: можно поправить
      и скопировать ещё раз.
    - **Умная формулировка** (`F2`) — локальная LLM убирает воду и
      структурирует текст. На коротких текстах (короче
      `llm.min_smart_chars`, по умолчанию 200 символов) кнопка
      недоступна: чистить там нечего, а модель легко «додумает» короткую
      фразу по-своему. Длинная диктовка в контекст не влезает, поэтому
      текст режется на куски и сжимается по частям; в метке видно
      «Формулирую часть 2 из 7». Пока модель думает, окно живое: под
      текстом бежит полоса, в метке тикают секунды, кнопка превращается
      в **Отменить**. Отменённый ответ просто выбрасывается.
    - **Отмена** (`Esc`) — закрыть без копирования (правки сохраняются
      в истории как `final`).
4. **Быстрый ввод.** `Ctrl+Alt+S` — то же распознавание, но без окна:
   текст сразу вставляется в прежнее окно и **не отправляется** (Enter
   не жмётся).
5. **Главное окно.** `Ctrl+Alt+Shift+D` — история записей: время,
   длительность речи, время распознавания, число символов, отметка о
   правке; вкладки «Записи» и «Лог». У выбранной записи текст в двух
   видах: распознанный (readonly) и отредактированный — правки в нём
   автосохраняются в JSONL (через 1,2 с бездействия), кнопка
   **Копировать** — отредактированный текст в буфер.

## Клавиши в окне — единые в живом режиме и в режиме правки

| Клавиши | Действие |
|---|---|
| `Backspace` | один символ (в живом режиме — и кусок аудио) |
| `Ctrl`/`Alt`+`Backspace` | слово (в живом режиме — и его аудио) |
| `Ctrl`/`Alt`+`Shift`+`Backspace` | фразу: до последней точки/`!`/`?`/`…` или до переноса строки |
| `Ctrl+Z` | отменить (история 100 шагов) |
| `Ctrl+Shift+Z`, `Ctrl+Y` | повторить |
| `Ctrl+C` | выделенное в буфер |
| `Ctrl+Shift+C` | весь текст в буфер |
| `Ctrl+Enter` | скопировать весь текст в буфер (в живом — стоп) |
| `F2` | умная формулировка / вернуть исходный |
| `Esc` | отменить запись / закрыть окно |

Во время записи `Backspace`, `Ctrl+Backspace` и `Ctrl+Shift+Backspace`
зарегистрированы глобально — управление диктовкой работает, даже если
фокус уехал из окна. Срезает и текст, и аудио: удалённое слово не
«возвратится» на следующем проходе распознавания. `Ctrl+Z` в живом
режиме отменяет только ручные правки (история сбрасывается при каждом
обновлении черновика); стёртое из аудио не восстанавливается.

## Горячие клавиши (глобальные)

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+D` | диктовка: окно с живым черновиком |
| `Ctrl+Alt+Shift+D` | главное окно: история, статистика, лог |
| `Ctrl+Alt+S` | быстрый ввод: распознал, вставил и всё; окна нет, Enter не жмётся |

Звуковые сигналы: писк при старте/стопе/готовности, гудок при ошибке,
короткий тик при стирании слова/фразы. Плашка внизу: `ЗАПИСЬ n с` →
`РАСПОЗНАЮ` → `СКОПИРОВАНО`.

## Модель и железо

- STT: `faster-whisper turbo`, CPU int8, 4 потока, beam 5.
- «Умная формулировка»: **`gemma4:e4b-it-q4_K_M`** (6,6 ГБ), фолбэк
  `qwen2.5:1.5b-instruct-q4_K_M`.
- GPU: `AMD Radeon RX 580 2048SP`, 8 ГиБ VRAM. Ollama грузит Gemma на
  GPU; ASR пока на CPU (GPU-миграция — whisper.cpp/Vulkan или DirectML —
  в планах, она же ускорит живой черновик).
- Экономия памяти ollama: `OLLAMA_FLASH_ATTENTION=1` и
  `OLLAMA_KV_CACHE_TYPE=q8_0` (подставляет сам `dictate.py` при запуске
  `ollama serve`).
- Thinking выключен (`llm.think: false`): Gemma 4 иначе уводит весь
  ответ в служебный канал.

### Замеры (i5-6600, 16 ГБ)

| Аудио | Время (turbo, beam 5) | RTF |
|---|---|---|
| 26 с | ~9–10 с | ~0.36 |
| 183 с | ~42,5 с | ~0.23 |
| 304 с | ~227 с | ~0.75 |
| 54 с | ~52 с | ~0.96 |
| 999 с | ~708 с | ~0.71 |

Beam 5 дороже greedy, но greedy на длинной диктовке терял целые фразы из
середины (на 183-с записи: 952–1314 символов против 1512). С `beam_size: 5`
и таймстемпами куски на месте, а таймстемпы же дают живому режиму
честную разбивку на «сказано / говорит сейчас».

## Файлы

```
dictate.py          приложение: хоткеи, запись, живой движок, ASR, история
ui.py               три окна: плашка статуса, окно правки, главное окно (Tk)
dictate.ico         иконка окон и панели задач
config.example.json пример настроек — скопируйте в config.json
models/             whisper turbo (CTranslate2)
ollama/             portable ollama.exe (сервер запускает сам dictate.py)
start-dictate.vbs   генерируется install.ps1
logs/               dictate.log + dictate-YYYY-MM-DD.jsonl
logs/audio/         wav последних диктовок (если save_audio: true)
```

Оформление — тёмная палитра в духе Tokyo Night: фон `#1f2335`, рамка
`#2f3b54`, текст `#c0caf5`, акцент `#7aa2f7`, шрифт Consolas.

## Установка и автозапуск

```bat
copy config.example.json config.json
powershell -ExecutionPolicy Bypass -File install.ps1
```

`config.json` в репозиторий не попадает: в нём пути и имя микрофона.
Модели тоже не коммитятся: `models/turbo` — CTranslate2-сборка
faster-whisper, `ollama/` — portable ollama с моделью
`gemma4:e4b-it-q4_K_M`.

install.ps1 ставит зависимости в `.venv`, генерирует `start-dictate.vbs`
и кладёт его в `shell:startup` (автозапуск без консоли). При старте
приложение прогревает whisper и LLM, поднимает `ollama serve`, если тот
не работает.

### ВАЖНО: запускать только в интерактивном сеансе

Хоткеи, вставка и окна работают только на **интерактивном рабочем столе**
(Default). Процесс из SSH-сессии или через WMI попадёт на «безголовый»
стол: запустится, но клавиши туда не дойдут. Поэтому:

- **Запустить сейчас** — двойной клик по `start-dictate.vbs`.
- **При каждом входе** — сам поднимется из `shell:startup`.
- **Остановка** — `powershell -File cleanup.ps1`.

### Почему видно два процесса pythonw

`pythonw.exe` из `.venv` — «лаунчер», который ре-запускает реальный
интерпретатор дочерним процессом. В диспетчере видна пара:
родитель-лаунчер (idle) + ребёнок (грузит модели). Это норма: мьютекс
`Local\local-dictate` гарантирует один экземпляр.

## Настройка (config.json)

- `hotkey` / `hotkey_raw` / `hotkey_main` — глобальные хоткеи (диктовка /
  быстрый ввод / главное окно).
- `live` — живой черновик: `enabled` (по умолчанию `false` — окно
  появляется только после распознавания), `draft_s` (хвост, который
  показывать жёлтым), `interval_s` (период перераспознавания),
  `context_s` (сколько уже замороженного аудио слушать заново на каждом
  проходе — страховка от потери слов на границе).
- `input_device` — подстрока имени микрофона; пусто = устройство по
  умолчанию. Список: `python dictate.py --devices`. Если микрофон
  подключили после запуска, приложение перечитывает устройства PortAudio
  и пробует заново.
- `whisper.model_dir` / `language` / `beam_size` / `threads`.
- `whisper.vad` — по умолчанию `false` (см. выше). При `true` действуют
  `vad_threshold` (0.10), `vad_min_silence_ms`, `vad_speech_pad_ms`.
- `llm.model` / `llm.fallback_model`; `llm.enabled: false` — формулировка
  отключена. `llm.min_smart_chars` — порог, короче которого формулировка
  не предлагается. `llm.min_ratio` / `llm.max_ratio` — границы длины
  ответа относительно исходника (слишком короткий/длинный отбрасывается).
- `save_audio` — сохранять распознанное аудио в `logs/audio` (16 кГц,
  mono). Нужно, чтобы разбирать «съело начало».
- `inject.mode` — `paste` (буфер + Ctrl+V) или `type` (посимвольно).
  Ввод через `SendInput`: у `keybd_event` поле скана однобайтовое, и
  кириллица в режиме `type` превращалась в латиницу. Быстрый ввод
  (`Ctrl+Alt+S`) вставляет текст и никогда не жмёт Enter.

## Диагностика

```bat
:: список устройств записи
.venv\Scripts\python.exe dictate.py --devices
:: прогнать wav через цепочку (тайминги + текст + формулировка)
.venv\Scripts\python.exe dictate.py --test test-ru.wav
:: тот же прогон без LLM
.venv\Scripts\python.exe dictate.py --test test-ru.wav --raw
:: полный end-to-end: приложение подставляет wav вместо микрофона
.venv\Scripts\python.exe dictate.py --fake test-ru.wav
:: перезапустить ollama с flash attention и KV q8_0
.venv\Scripts\python.exe dictate.py --restart-ollama
```

Журнал: `logs\dictate.log`; каждая диктовка — строка JSONL в
`logs\dictate-<дата>.jsonl` (`action: copy|send|cancel`, `sec`,
`asr_ms`, `llm_ms`, `smart`, `raw`, `final`, `wav`) — по нему живёт
главное окно и настраивается промпт.

## Ограничения

- Живой черновик на CPU обновляется с задержкой ~RTF·хвост (8–14 с):
  последние несколько слов видны с опозданием. Финальный проход при
  остановке всё равно верифицирует целиком.
- Стирание в живом режиме режет аудио: `Ctrl+Z` вернёт только ручные
  правки текста, но не стёртое слово (аудио уже обрезано).
- Gemma 4 E4B занимает почти всю видеопамять; игры/графические
  приложения одновременно с формулировкой могут не поместиться.
- whisper `turbo` на русском рабочий; если качество захромает:
  `large-v3` (медленнее ~2x) либо GigaAM (Sber, CTC, лучше на русском,
  но без пунктуации).
